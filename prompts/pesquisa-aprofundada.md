# Prompt de Pesquisa Aprofundada

Criador: Alexandre Barroso de Miranda  
Atuação: Consultor de Processos  
Método: PACTO

```text
Faça uma pesquisa aprofundada na internet sobre as melhores práticas atuais para desenvolvimento de software com agentes de código, especialmente Claude Code e OpenAI Codex.

Objetivo: descobrir como criar um framework/passo a passo realmente bom para iniciar, planejar, desenvolver, testar, revisar e finalizar projetos usando agentes de código.

Não parta dos meus prompts atuais como verdade. Investigue do zero e, se necessário, contradiga totalmente a ideia inicial.

Pesquise obrigatoriamente:
- documentação oficial do Claude Code, OpenAI Codex, AGENTS.md, GitHub Copilot/Coding Agent, Cursor e Gemini CLI;
- fóruns e comunidades como Reddit, Hacker News, Stack Overflow/Stack Exchange, GitHub Issues/Discussions e Discords públicos quando acessíveis;
- vídeos relevantes do YouTube sobre workflows reais com Claude Code, Codex, Cursor, Copilot, TDD, spec-driven development e agentic coding;
- artigos técnicos de pessoas com experiência prática construindo projetos reais com agentes.

Procure responder:
1. Qual fluxo de trabalho aparece com mais frequência entre usuários avançados?
2. O que a documentação oficial recomenda?
3. Quais práticas são consenso entre fontes diferentes?
4. Quais práticas são controversas ou dependem do contexto?
5. Quais arquivos de instrução e documentação são realmente úteis?
6. Como escrever uma boa SPEC para agentes?
7. Quando pedir planejamento antes de código?
8. Quando usar TDD, testes primeiro ou testes depois?
9. Como evitar loops, perda de contexto, retrabalho e “vibe coding” ruim?
10. Como dividir trabalho entre humano e agente?
11. Como adaptar o processo para projeto do zero versus projeto existente?
12. Como adaptar o processo para projetos pequenos versus grandes?
13. O que deve acontecer fora do chat e o que deve acontecer dentro do chat?
14. Quais prompts ou padrões de prompt são recomendados?
15. Quais antipadrões aparecem com frequência?

Entregue o resultado em português do Brasil, com:
- resumo executivo;
- tabela comparando recomendações por fonte;
- lista de práticas recomendadas com nível de confiança: alto, médio ou baixo;
- lista de antipadrões;
- proposta de framework do zero, sem obrigação de seguir minhas ideias;
- exemplos de prompts curtos;
- links das fontes usadas;
- data de publicação ou acesso quando disponível;
- separação clara entre fato documentado, relato de comunidade e sua inferência.

Se encontrar fontes conflitantes, mostre o conflito e explique qual abordagem parece mais robusta.
```
