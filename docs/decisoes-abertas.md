# Decisões Abertas

Criador: Alexandre Barroso de Miranda
Atuação: Consultor de Processos
Método: PACTO

Registro de decisões. As propostas históricas não substituem os modelos oficiais em templates/.

## 1. Forma final do framework

- Manual/checklist único.
- Kit de templates.
- Ambos, com um fluxo enxuto para projetos pequenos e um fluxo completo para projetos maiores.

Resposta atual do usuário: **ambos**.

## 2. Ferramentas prioritárias

- Claude Code.
- Codex.

Resposta atual do usuário: **Claude Code e Codex**.

## 3. Stack

O framework deve ser independente de stack.

Resposta atual do usuário: **independente**.

## 4. Nível de documentação

Decidido: tarefa trivial não exige documentos novos; criar e preencher somente contratos necessários. PLAN e BRIEF são condicionais.

## 5. Papel do usuário humano

Ponto em aberto: definir exatamente quais decisões o agente nunca deve assumir sozinho.

## 6. Pesquisa

Status: relatórios recebidos e copiados para `research/`.

Síntese criada em `docs/sintese-pesquisa.md`.

## 7. Nome do framework

Nome definido: **Método PACTO**.

PACTO significa: Preparar, Avaliar, Contratar, Trabalhar e Observar.

## 8. Regra de parada

Decidido: três tentativas no mesmo erro como teto geral, com parada antecipada por risco ou falta de evidência nova.

## 9. Templates finais

Consolidados em templates/, com cópias idênticas dos cinco modelos principais no kit. Licença e distribuição final continuam pendentes.
